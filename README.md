## Em construção

| Projeto | O que é | Stack |

| **[EchoSense](https://github.com/tarsyllammassoli/EchoSense)** | Monitoramento de bem-estar animal por visão computacional (InovaWeek) | React · Vite · Recharts |

## Como eu trabalho

Cada projeto tem o próprio canvas no **Maestri**, com um time de agentes de IA.
Eu decido o quê e o porquê; o Maestro divide o trabalho, os agentes constroem, um revisa, outro testa, e nada vai pra produção sem o meu ok.

<img src="assets/time.svg" width="100%" alt="Time de agentes no Maestri: Maestro (Claude Code, opus) planeja e integra; Prisma (Claude Code) telas; Forja (Codex) API e banco; Sentinela (Codex) testes; Lupa (Claude Code) revisão e segurança; Radar (Antigravity) pesquisa; Eco e Pena (OpenCode) tarefas braçais e textos." />
